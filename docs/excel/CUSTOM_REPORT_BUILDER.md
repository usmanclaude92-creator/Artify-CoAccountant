# Custom Report Builder and Standard Reports

**Governed datasets only** (`xl_catalogue.DATASETS`): transactions, transaction lines, journal lines/listing, trial balance, account balances, general/account ledger, profit and loss, balance sheet data, sales / purchase / expense / receipts / payments registers, customer and supplier ledgers, receivables and payables summaries, VAT summary and VAT transactions, bank transactions and summary, expense analysis, dimension summary. Each has a fixed SQL statement in `xl_data.py`, declared fields and filters, an honest `note`, and `statutory = false`.

**Standard reports** run those datasets with their declared filters (`POST …/reports/standard/{key}/run`, paged). An undeclared filter is refused (422), not ignored. They are **management information from approved data — not statutory filings**; the VAT datasets are summaries of configured tax codes, not a VAT return. Balance sheet / P&L show "Result for the period (not closed to equity)" because Artify does not close periods.

**Custom reports** (`feature.report_builder`, `limit.custom_reports_per_company`): a definition names one dataset, 1–40 of its fields, optional sort, one `group_by` (summing money fields with `Decimal`) and filters. Validation rejects unknown datasets/fields/filters, so **no arbitrary SQL, expressions or table access is possible**. A report may be associated with an Excel template and exported through the normal export path (history, quota, traceability). Runs are recorded (`xl_report_runs`: who, parameters, row count). Archiving never deletes.
